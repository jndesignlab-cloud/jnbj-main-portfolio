# Jann Jaravata Portfolio v1.0.0

Editorial personal portfolio foundation for `jannjaravata.madebydesignlab.com`.

## Included
- Responsive static website
- Light and dark modes
- Scroll reveal animations
- Blue-forward DesignLab visual system
- Hero, selected work, capabilities, about, experience, contact, and footer
- CSS-built placeholder project visuals
- GitHub Pages compatible

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to a new repository, enable GitHub Pages, then connect the subdomain.

## Update first
Replace the placeholder email, case-study links, project descriptions, and any timeline details inside `index.html`.
